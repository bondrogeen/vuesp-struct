# Design

## Approach

Baseline фиксирует текущий публичный контракт библиотеки по README, `src/` и
тестам. Внутренние классы и структуры парсера в спеки не входят.

## Capability boundaries

| Capability | Отвечает за | Не отвечает за |
|---|---|---|
| `protocol-parser` | C++ → JSON, layout, ошибки разбора | кодирование сообщений |
| `protocol-codec` | значения ↔ байты, размеры, ошибки путей | разбор исходников |

## Decisions

1. **Packed layout — обязательный.** Размеры и смещения считаются без паддингов;
   это совпадает с C++-структурами прошивки.
2. **Запрос — только ключ.** `set(key)` без payload даёт кадр из одного байта;
   кадр полной длины означает запись.
3. **Ошибки с путём.** И кодек, и парсер сообщают место ошибки, чтобы прошивка
   и UI могли показать понятную причину.

## Non-goals

- Генерация `protocol.generated.h` и TS-констант в приложениях.
- Версии протокола, отличные от 2.
- Внутреннее устройство токенайзера.
